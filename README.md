
# 🌿 Bostan Nursery

Bostan Nursery is a simple, clean, and responsive website built using **HTML5** and **CSS3**.  
The project represents a nursery and garden care business that provides plants, flowers, landscaping, and garden maintenance services.

🔗 **Live Website:**  
https://ayaahmed50.github.io/Bostan-Nursary/

🔗 **GitHub Repository:**  
https://github.com/AyaAhmed50/Bostan-Nursary

---

## 🌱 About the Business

**Bostan Nursery** focuses on delivering high-quality plants and garden solutions.  
The business aims to help customers create beautiful green spaces by offering:

- A wide variety of plants and flowers  
- Garden care and maintenance services  
- Landscape and garden design consultation  
- Cost-effective pricing with promotions and discounts  
- Expert advice from experienced garden specialists  

Customer satisfaction, plant health, and sustainable gardening are at the heart of the business.

---

## 💻 Technologies Used

- **HTML5** – Page structure and content  
- **CSS3** – Styling, layout, and responsiveness  
- **Google Fonts & Icons** – For modern typography and icons  

⚠️ This project does **not** use JavaScript or any backend technologies.

## 🚀 How to Clone and Run the Project

Follow these steps to run the project locally:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/AyaAhmed50/Bostan-Nursary.git
````

### 2️⃣ Navigate to the project folder

```bash
cd Bostan-Nursary
```

### 3️⃣ Open the project

Simply open `index.html` in your browser
(or use Live Server if you are using VS Code).
